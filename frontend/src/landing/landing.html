Ways to connect today

  • Add a few lines to a Python agent. The Trovis SDK records agents built with supported frameworks, such as the OpenAI Agents SDK and the Claude Agent SDK.
  • Send OpenTelemetry traces. Custom agents and tools that already emit OpenTelemetry can send their traces to Trovis.
  • Install a plugin on a supported agent platform, such as OpenClaw.
  • Connect supported business tools, starting with Stripe, HubSpot, and Shopify, to see the work they record.

Not every platform is supported yet. Tell us which agents and workflows you use when you request access.
